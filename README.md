# The Takeout Box

> Restaurant Supply & Wholesale Packaging e-commerce platform built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS / custom styling, and an Express & MySQL backend service.

## 🚀 Overview

The Takeout Box is a specialized wholesale and retail food packaging platform providing:
- **Comprehensive Product Catalog**: Over 300+ restaurant packaging products (cups, containers, lids, bags, boxes).
- **Interactive Ordering Experience**: Real-time cart calculation, wholesale quote requests, and order management.
- **Modern Tech Stack**: Next.js 16 with Turbopack, React 19, TypeScript, and Express backend API.

## 🛠️ Tech Stack

- **Frontend**: Next.js 16, React 19, TypeScript, GSAP, Lucide React, HTML2Canvas, jsPDF
- **Backend**: Express, TypeScript, MySQL2, Firebase Admin, Nodemailer, Zod
- **Authentication**: JWT & Firebase Auth / Google OAuth support

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Frontend Setup
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Backend Setup (Optional for standalone mode)
```bash
cd server
npm install
npm run dev
```

## 📦 Production Build
```bash
npm run build
npm start
```
